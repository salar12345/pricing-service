# Implementation Plans

Write a plan here **before** starting any feature or change.

## Naming

`docs/plans/<feature-name>.md` — e.g. `quote-endpoint.md`, `idempotency.md`

## Template

```markdown
# [Feature name]

## Status
planned | in-progress | done

## Goal
What this change achieves.

## Scope
- In scope: ...
- Out of scope: ...

## Design
API changes, DB schema, domain logic, file layout.

## Test plan
- [ ] Unit: ...
- [ ] Integration: ...

## Files to create/modify
- `app/...`
- `tests/...`

## Notes
Decisions, trade-offs, open questions.
```

When done, set status to `done` and note any deviations from the plan.
